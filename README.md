# Bluemug releases

Installers for **Bluemug**, a quiet reader for the newsletters in your Gmail.

Grab the latest Windows setup from the [releases page](../../releases). The
installed app updates itself from here, so this is a one-time download.

The build is not code-signed yet, so Windows SmartScreen warns the first time:
**More info → Run anyway**.

Bluemug was called Hermes until version 0.2.28. It is the same app under a name
that was not already taken. The rename gives Windows a new install and a new
settings folder, so Hermes is uninstalled by hand and Gmail is connected once
more; nothing in Gmail changes, and the newsletters, their read and archived
state and the filters carry over untouched.

This repository holds only the published installers. The source lives
elsewhere, and nothing here reads your mail.
